# Portfolio review
Use this mode when the request compares multiple managed records in one domain or explicitly asks for a compact cross-domain capacity review.
## Review
1. Confirm one selected domain. Compare domains only when the user explicitly requests it.
2. Establish the review horizon and available capacity when the user wants recommendations rather than factual inventory. Ask only when missing capacity, deadlines, or hard stops would materially change the result; otherwise state a conservative assumption.
3. Inventory candidate records shallowly from underscore-prefixed, folder-matching homes. Fully load only records marked `pm_scope: managed` in scope. Report excluded or unclassified records without letting them influence recommendations.
4. For managed records, load the home, current `xPM/Status.md`, and latest `xPM/Handoff.md`. Load Decisions or per-item Notes only under the shared policy's routing conditions.
5. Compare active outcomes, necessary Area maintenance, blockers, dependencies, deadlines, and income relationship without inventing scores or false precision.
6. Recommend one primary focus and at most one secondary maintenance responsibility. Explain displacement and identify work that should remain planned, paused, or outside scope.
## Cross-domain boundary
A cross-domain review compares compact commitments long enough to allocate limited attention, then returns detailed management to one selected domain. Do not turn visibility into simultaneous management of every domain.
