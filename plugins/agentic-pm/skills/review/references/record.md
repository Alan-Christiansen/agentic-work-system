# Area or Project review
Use this mode for stewardship of one initialized Area or review of one active, planned, blocked, or paused Project.
## Load current state
1. Reread the underscore-prefixed, folder-matching home.
2. Load `xPM/Status.md` and the latest `xPM/Handoff.md`.
3. Load Decisions only when the review could affect or reopen an accepted management choice.
4. Load an `AT-*` note only for a selected, blocked, due, or otherwise relevant Area task. Load candidate detail only when the user asks to review that candidate.
## Review an Area
- Confirm it remains an ongoing responsibility without inventing a finish line.
- Assess healthy-state coverage, necessary maintenance, open and blocked tasks, scheduled follow-ups, stale urgency, and inactive candidates that need attention.
- Recommend one maintenance action that fits the session envelope. If no action is needed, say so rather than manufacturing work.
- Preserve the separation between bounded Area tasks and inactive project candidates.
## Review a Project
- Assess its active outcome, progress toward the definition of done, current tasks, blockers, dependencies, deadlines, stale state, and whether the recorded next action still fits.
- Recommend one action or management decision that advances, unblocks, pauses, resumes, completes, or responsibly retires the Project.
- Treat lifecycle, priority, scope, objective, and definition-of-done changes as proposals requiring explicit approval.
## Authorized maintenance
When the user separately authorizes maintenance, reconcile only accepted task markers, urgency, factual home mirrors, Status, and Handoff. Preserve unrelated human state and record a Decision only when an accepted choice could otherwise be reopened.
