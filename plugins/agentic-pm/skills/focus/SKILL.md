# Agentic PM: Focus
Read [the shared operating policy](../../references/operating-policy.md) completely before acting.
## Select the focus mode
Infer the horizon and working state from the request, then read only the matching reference:
- For a week or another short multi-day horizon, read [weekly focus](references/weekly.md).
- For a bounded work session, immediate next action, or stuck state, read [session focus](references/session.md).
Ask only for missing time, energy, attention, hard-stop, or dependency information that would materially change the result. Otherwise state a conservative assumption. Do not make the user select an internal mode when the horizon is clear.
## Shared boundaries
- Work from an accepted direction or current primary outcome. If competing commitments make the direction itself unresolved, recommend `agentic-pm:review` before manufacturing a plan.
- Prefer work that advances the primary outcome, removes an active constraint, or prevents a near-term cost. Do not switch merely because another task is easier or newer.
- A focus request is read-only. Do not mark work in progress, change canonical tasks or next actions, or execute the represented work unless the user separately asks.
- Keep later work visibly later and name what should not receive attention during the chosen horizon.
## Deliver
Lead with the primary outcome or one imperative action. State its finish condition, why it fits the available capacity, the first physical or digital move, displacement, and the condition that would trigger replanning.
