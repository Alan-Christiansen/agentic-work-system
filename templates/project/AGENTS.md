# Start here
1. Read `_Project Name.md`.
2. Read `xPM/Status.md`.
3. Read `xPM/Handoff.md`.
4. Read `xPM/Decisions.md` only when the task could affect or reopen an accepted decision.
5. Load requirements and deeper working files only when the current task requires them.
## Operating boundary
- The project home owns its objective, definition of done, boundaries, human tasks, and approved agent role. Status owns detailed current state; Handoff owns restart context.
- Treat saved next actions as state, not authorization to execute them. A linked repository does not authorize implementation.
- Preserve unrelated work and obtain approval before structural, lifecycle, scope, destructive, or external changes.
- Treat links outside this folder as informational unless the user explicitly grants access.
